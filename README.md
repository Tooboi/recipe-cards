
# Recipe Card Vault

Next.js website for posting and storing recipes as well as exporting them as pdf documents on mobile and desktop.

![GitHub last commit (branch)](https://img.shields.io/github/last-commit/Tooboi/recipe-cards/main)

## Installation

Install recipe-cards with npm

```bash
  npm install
```
    
## Features

- Mobile/Desktop
- Live pdf previews
- Add images
- Bookmark favorite recipes
- User authentication


## Tech Stack

**Client/Server:** Next.js app router, TailwindCSS, Prisma, Cloudinary

**Auth:** NextAuth

**Deployment:** Vercel, MongoDB
